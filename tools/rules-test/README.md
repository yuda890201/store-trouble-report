# firestore.rules のテスト

`firestore.rules` を書き換えたら、本番に貼る前にここで確かめます。
ルールを間違えると報告が 1 件も送れなくなるため、目視だけで済ませないでください。

## 動かし方

Node.js と Java が必要です（エミュレータが Java で動きます）。

```bash
cd tools/rules-test
npm install
npm test
```

`ALL GREEN` が出れば通っています。失敗した項目は名前付きで表示されます。

テストは `../../firestore.rules`（本番に貼るファイルそのもの）を読み込んでエミュレータに
流し込みます。`firebase.json` 側にはルールを書いていません（エミュレータの設定はプロジェクト
ディレクトリの外を参照できないため）。

## 何を見ているか

- 店舗アカウント（`fm0001@fm.example.com` のような `fm`＋数字）
  - 報告を作れる / 読める / ステータスだけ変えられる
  - 本文が空・長すぎる・報告者が空なら作れない
  - 本文の書き換えと削除はできない
- 閲覧アカウント（店舗コミュニケーションアプリ用。別ドメイン）
  - 読める
  - **作れない・変えられない・消せない**
- `fm0001@fm.example.com.evil.com` のような似たアドレスでは書けない
- 未ログインでは読むことも書くこともできない
- `trouble_reports` 以外のコレクションには触れない
